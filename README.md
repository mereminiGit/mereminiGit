### About

여러 제조업체의 MES·ERP 구축과 고도화에 참여하며, 현업 요구사항을 화면·서버·DB에 구현해 왔습니다. 업무 모듈 개발부터 데이터 검증, 사용자 교육과 시스템 오픈까지 연결된 업무를 다뤘습니다.

- **업무 시스템 개발** — 영업·구매·외주·무역·생산·품질·재고 기능 개발·개선
- **데이터 연계와 검증** — 외부 API 연동, 전표 간 데이터 연계, 조회 쿼리 개선
- **현장 업무 지원** — 바코드·PDA 화면, 자동검사기 파일 수집, 사용자 교육
